# Experimentos

* ```PruebaGeneralFase1/```: Experimentos de la Fase 1.
  * ```PruebaGeneralFase1.ino```: Código Arduino con el que se realizan las medidas ante estímulos preprogramados y, posteriormente, se envían por puerto serie.
  * ```Archivos .xlsx```: Datos obtenidos en los experimentos de la Fase 1.
* ```PruebaGeneralFase2/```: Experimentos de la Fase 2.
  * ```PruebaGeneralFase2.ino```: Código Arduino con el que se realizan las medidas ante estímulos preprogramados y, posteriormente, se envían por puerto serie.
  * ```Archivos .xlsx```: Datos obtenidos en los experimentos de la Fase 2.
* ```PruebaHisteresisFase2/PruebaHisteresisBomba```: Contiene tanto el código Arduino para el experimento de histeresis de la bomba como los datos obtenidos en este.
* ```PruebaHisteresisFase2/PruebaHisteresisValvula```: Contiene tanto el código Arduino para el experimento de histeresis de las válvulas como los datos obtenidos en este.
* ```Graficador.m```: Archivo Matlab con el que poder visualizar los datos obtenidos en los distintos experimentos.
